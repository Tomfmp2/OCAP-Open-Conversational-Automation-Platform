## 🌟 Executive Summary

Nos complace anunciar el lanzamiento de **OCAP (Open Conversational Automation Platform) v2.1.0 General Availability (GA)**.

OCAP es una plataforma enterprise de automatización conversacional y orquestación de agentes con IA Generativa, arquitectura hexagonal limpia en .NET 10, bus de eventos distribuido, motor de flujos visual, autenticación multi-tenant y sincronización de directorios corporativos.

---

## 🚀 Key Features & Capabilities (CAP-01 → CAP-20)

### 1. High-Performance Core Architecture (.NET 10 & Clean Hexagonal)
- Arquitectura Hexagonal pura (Puertos y Adaptadores) impulsada por C# 14 y .NET 10.
- Rendimiento ultra rápido con latencias P95 < 15 ms en operaciones concurrentes.

### 2. Multi-Tenant Security & Identity Management
- Servidor de Autorización OAuth2 / OpenID Connect basado en **OpenIddict** con soporte para **Authorization Code Flow + PKCE (RFC 7636)**, **Client Credentials** y **Refresh Tokens**.
- **Multi-Factor Authentication (MFA)**: TOTP (RFC 6238) con códigos de recuperación cifrados y **Passkeys WebAuthn / FIDO2** nivel 2.
- **External Identity Providers**: Google, Microsoft Entra ID (Azure AD), GitHub y proveedor OpenID Connect genérico.
- **Enterprise SSO SAML 2.0**: Service Provider (SP), SP-Initiated & IdP-Initiated SSO, ACS, SLO y firmado XML.
- **Enterprise Directory Synchronization**: SCIM 2.0 (RFC 7643/7644) y motor de sincronización de directorios activos **LDAP / Active Directory**.

### 3. Distributed Event Bus & High Availability Clustering (CAP-20)
- Bus de eventos distribuido desacoplado (`DistributedEventBus`) con soporte para **RabbitMQ Cluster** y **NATS JetStream**.
- Garantías de entrega y consistencia con **Outbox Pattern**, **Inbox Pattern (Idempotencia)** y **Dead Letter Queue (DLQ)**.

### 4. Conversational Channels & AI Orchestrator
- Adaptadores de canal en tiempo real para **Telegram**, **WhatsApp (Evolution API)**, **WebChat**, **Discord** y **Microsoft Teams**.
- Orquestador inteligente de IA Generativa con failover automático entre **OpenAI**, **Google Gemini**, **Anthropic Claude** y **Ollama (Self-Hosted)**.
- Motor RAG (Retrieval-Augmented Generation) integrado con vector stores (pgvector, Qdrant, ChromaDB, Pinecone).

### 5. Visual Workflow Automation & Dashboard
- Diseñador visual de flujos de trabajo (Visual Workflow Builder) drag-and-drop con Blazor WebAssembly y React / Next.js.
- Canal en tiempo real **SignalR Live Gateway (`/hubs/events`)** para streaming de eventos y respuestas de IA.

## ⏱️ Quick Start Guide (Install in < 10 Minutes)

### Option A: Docker Compose Quick Start

```bash
# 1. Clone Repository
git clone https://github.com/ocap-project/ocap.git
cd ocap

# 2. Run with Docker Compose
docker-compose up -d

# 3. Access Services
# - API Gateway: http://localhost:5000/swagger
# - Dashboard SPA: http://localhost:5001
# - Health Checks: http://localhost:5000/health
```
